# IT1214-Warehouse-Inventory-System

## Project Description
A simple Warehouse Inventory Management System using Java Collections Framework.

## How to Run
1. Compile all `.java` files:
   javac Item.java Inventory.java Warehouse.java
2. Run the program:
   java Warehouse

## Sample Output
--- Warehouse Menu ---
1. Add Item
2. Remove Item
3. Update Quantity
4. Search Item
5. Display All Items
6. Exit
